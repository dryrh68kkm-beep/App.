# DeptFlow · แยกไฟล์ PDF พนักงานตามแผนก (แอปมือถือ)

เว็บแอปสำหรับ iPhone / Android ที่ติดตั้งลงหน้าจอโฮมได้ **ทำงานในมือถือเครื่องนั้นทั้งหมด**
ไฟล์ PDF ไม่ถูกส่งออกไปที่ใด ไม่ใช้ OCR และใช้งานได้แม้ไม่มีอินเทอร์เน็ต (หลังเปิดครั้งแรก)

> ⛔ **ห้ามนำเอกสารพนักงานขึ้น repository นี้** ได้แก่ PDF ต้นฉบับ PDF ที่แยกแล้ว ZIP ภาพหน้าจอ log หรือข้อมูลพนักงานใด ๆ
> repository นี้เก็บเฉพาะ **โค้ดของแอป** ตามที่เจ้าของโปรเจกต์อนุญาตให้ใช้ GitHub Pages

## ใช้งาน

1. เปิดลิงก์ GitHub Pages ของ repo นี้ใน **Safari** (iPhone) หรือ **Chrome** (Android)
2. **ติดตั้งลงหน้าจอโฮม**: Safari › ปุ่มแชร์ › *เพิ่มไปยังหน้าจอโฮม*
3. แตะ **เลือกไฟล์ PDF** แล้วเลือกไฟล์รวม เช่น รายงานเวลาทำงาน HRAL61X จากแอป Files หรือ LINE
4. **กำหนดแผนก**
   - ดูชื่อหน่วยงานจากภาพหัวเอกสารของแต่ละหน้า (แตะภาพเพื่อดูทั้งหน้า)
   - เลือกหรือพิมพ์ชื่อแผนก **เฉพาะหน้าแรกของแต่ละแผนก** หน้าถัดไปจะใช้แผนกเดียวกันจนกว่าจะเปลี่ยน
   - หน้าที่ไม่ต้องการ แตะ **ยกเว้นหน้านี้**
   - ถ้า PDF มีข้อความ แอปจะเติมชื่อแผนกให้ก่อน ต้องตรวจอีกครั้ง
5. แตะ **สร้างไฟล์** แล้วตรวจว่าขึ้น **✓ ครบ x/x หน้า ไม่ซ้ำ**
6. แต่ละแผนก: **ดูหน้า** เพื่อตรวจ หรือ **แชร์ / บันทึก**
   - ติ๊กยืนยันว่าปลายทางได้รับอนุญาต แล้วเลือก LINE กลุ่มที่ถูกต้อง หรือ *บันทึกไปยังไฟล์*
7. **บันทึกทั้งหมด (ZIP)** ได้ไฟล์ ZIP รวมทุกแผนก
8. ใช้เสร็จแล้วแตะ **ล้างข้อมูล** หรือปิดแอป

หน้าที่ยังไม่ระบุแผนกจะอยู่ในไฟล์ **รอตรวจสอบ** แอปไม่เดาแผนกให้

## เปิดใช้ GitHub Pages (ทำครั้งเดียว)

1. ไปที่ **Settings › Pages** ของ repository
2. หัวข้อ *Build and deployment* › Source: **Deploy from a branch**
3. Branch: เลือก branch ที่มีโค้ดนี้ แล้วเลือกโฟลเดอร์ **/ (root)** แล้วกด **Save**
4. รอประมาณ 1–2 นาที ลิงก์จะขึ้นที่หน้าเดียวกัน เช่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ตั้งค่า (`config.js`)

| ค่า | ใช้ทำอะไร |
|---|---|
| `DEPARTMENTS` | รายชื่อแผนกให้เลือก และใช้เป็นชื่อไฟล์ (พิมพ์ชื่อใหม่ในแอปได้เสมอ แอปจะจำชื่อที่พิมพ์เพิ่มไว้ในเครื่อง) |
| `HEADER_BOX` | กรอบภาพหัวเอกสาร `[ซ้าย, บน, ขวา, ล่าง]` เป็นสัดส่วนของหน้า |
| `DEPARTMENT_PATTERNS` / `HEADER_AREA` | ใช้กับ PDF ที่มีข้อความเท่านั้น: อ่านชื่อแผนกจากหัวเอกสารเพื่อเติมล่วงหน้า |
| `ALIASES` | เปลี่ยนชื่อที่อ่านได้เป็นชื่อที่ต้องการ |

ห้ามใส่ชื่อหรือรหัสพนักงานจริงลงใน `config.js`
ถ้าแก้ไฟล์ใด ๆ ให้เปลี่ยนเลขเวอร์ชัน `CACHE` ใน `sw.js` เพื่อให้มือถือโหลดแอปรุ่นใหม่

## โครงสร้าง

```
index.html            หน้าแอป (มี Content-Security-Policy: โหลดได้เฉพาะไฟล์ของแอปเอง)
app.js                ขั้นตอนหลัก: เปิดไฟล์ → กำหนดแผนก → สร้างไฟล์ → แชร์
splitter.js           แบ่งหน้าตามแผนก ตรวจว่าครบทุกหน้าและไม่ซ้ำ
detect.js             เติมชื่อแผนกจาก PDF ที่มีข้อความ (ไม่ใช้ OCR)
zip.js                สร้าง ZIP ในเครื่อง
config.js             รายชื่อแผนกและค่าตั้งค่า
sw.js                 เก็บไฟล์แอปไว้ใช้ออฟไลน์ (ไม่เก็บเอกสาร)
manifest.webmanifest  ข้อมูลสำหรับติดตั้งเป็นแอป
vendor/               pdf.js 4.10.38 (Apache-2.0) และ pdf-lib 1.17.1 (MIT) พร้อมไฟล์ไลเซนส์
tests/                ตัวสร้าง PDF จำลอง + เทสต์ครบขั้นตอน (ข้อมูลจำลองเท่านั้น)
SECURITY.md           มาตรการป้องกันข้อมูลรั่วไหล
```

## ทดสอบ (ข้อมูลจำลองเท่านั้น)

```
pip install pymupdf playwright
python -m http.server 8800 --bind 127.0.0.1
python tests/e2e_test.py
```

## คำถามพบบ่อย

**แชร์แล้วไม่เห็น LINE**: เลื่อนแถวแอปในเมนูแชร์ไปทางขวา แล้วแตะ *เพิ่มเติม* เพื่อเปิด LINE

**ต้องการเก็บไฟล์ไว้ในเครื่อง**: แตะ *แชร์ / บันทึก* แล้วเลือก *บันทึกไปยังไฟล์*

**เปิดไฟล์จาก LINE**: ใน LINE แตะไฟล์ › ปุ่มแชร์ › *บันทึกไปยังไฟล์* ก่อน แล้วค่อยเลือกจาก DeptFlow

**แอปไม่อัปเดตเป็นรุ่นใหม่**: ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง
